# ERIKA documentation by stakeholder

Pick the guide for your role. The guides for users of the app are in German, because ERIKA's users are German businesses and their tax advisors. The guides for the team behind ERIKA are in English, like the rest of the repository.

| You are | Read | Language |
|---|---|---|
| **Business owner or employee** using ERIKA | [Handbuch für Inhaber und Mitarbeiter](nutzerhandbuch.md) | Deutsch |
| **Tax advisor** of an ERIKA customer | [Handbuch für die Steuerberatung](steuerberatung.md) | Deutsch |
| **Management / product owner** deciding what comes next | [Product overview](product-overview.md) | English |
| **Operator or support** running ERIKA and answering users | [Operations and support](operations-and-support.md) | English |
| **Developer** joining the project | [Developer onboarding](developer-onboarding.md) | English |
| **Data protection officer, lawyer, auditor, reviewing tax advisor** | [Compliance overview](compliance-overview.md) | English |
